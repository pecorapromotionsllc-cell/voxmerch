# voxmerch-marketing-site

The public website: voxmerch.com. Landing pages, sales pages, how-it-works pages. Also code, but a different beast from the platform itself — different audience, different goals, different files.

## Current contents

- `external-skills/claude-seo-main/` — Claude SEO plugin for audits, schema, backlinks, technical SEO, content, local/programmatic SEO. See `../docs/external-skills.md`.

## What goes here
Site code, page templates, CSS, SEO artifacts (sitemaps, robots.txt configs, schema templates), conversion experiments.

## What does NOT go here
Product code (→ `voxmerch-platform/`), blog and social copy (→ `voxmerch-content/`).
